# Proposal: Blocked status token

Triage: ready-for-agent

## Why

The `blocked-tasks` change defined a Blocked task as one whose text ends with a plain ` — blocked`, but the projects' `tasks.md` files are generated by `/triage`, which writes the status as a backticked token after the issue link, sometimes followed by a note: `` — `blocked` `` or `` — `blocked` — the writing tier; waits on … ``. Run over the three projects' active `tasks.md` files, osviz finds 0 Blocked tasks among the 29 unticked tasks that are blocked or mention it. The files must not be hand-edited, so osviz has to read the format `/triage` writes.

## What Changes

- A **Blocked task** is an unticked task whose text contains the status token `` — `blocked` ``: a space, an em dash (U+2014), a space, then `blocked` in lowercase between backticks, followed by a space or by the end of the text (trailing whitespace removed). A note may follow the token.
- **BREAKING** (for the previous rule only): a task ending in a plain ` — blocked`, without backticks, is no longer a Blocked task. No project writes that form; keeping both would leave two definitions.
- `blocked` written as a dependency note, as in `` — `ready-for-agent` — blocked by 04 ``, is not a Blocked task: the status token there is `ready-for-agent`.
- The row's `blocked` marker, the panel's yellow `⊘`, Task progress and the `issues/`-not-read rule are unchanged; they follow the new definition.

Out of scope: other `/triage` status tokens (`ready-for-agent`, `needs-info`, …); reading `issues/`; showing what a task is blocked by.

### Modified Capabilities
- `project-reading`: the Blocked tasks requirement matches the backticked status token instead of the plain suffix.
- `change-list`: the Blocked marker scenario's example task uses the status token.
- `detail-panel`: Task lines show a Blocked task's text as written, status token and note included.

## Impact

- `src/tasks.ts`: `BLOCKED_SUFFIX` becomes ``BLOCKED_STATUS = / — `blocked`(?: |$)/``.
- `test/app.test.tsx`: the Blocked marker, Task lines and Blocked tasks tests move to the `/triage` form.
- `CONTEXT.md`: the **Blocked task** definition.
